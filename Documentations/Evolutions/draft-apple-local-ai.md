# 原生 Apple 本地模型后端

- **状态**: Accepted
- **创建日期**: 2026-11-15
- **最后更新**: 2026-11-15

## 摘要

用户明确要求增加原生 Apple 本地模型后端。共享 AI 控制器新增 Foundation Models 适配，直接调用端侧模型；不启动 fm CLI、不使用 PCC、不实现歌词净化。

## 方案与边界

- 共用服务增加后端选择：OpenAI 兼容／Apple 本地模型。旧配置无新键时仍选择 OpenAI 兼容，不自动更改已有选择。
- 本地模式无远程端点、API key 或 HTTP 请求，不读取钥匙串、不自动回退云端；可显示系统、模型可用性、支持语言与上下文状态。
- 使用原生 FoundationModels，macOS 26+可用；旧系统继续运行原远程服务，明确显示本地后端需要新系统。
- 本地模型请求独立 session 和取消，保留任务端的分批、重试总预算。调用方以通用输出 schema 描述结果，原生适配器使用 Foundation Models guided generation；翻译 schema 归翻译任务所有，不把业务字段写进共享控制器。上下文错误由任务拆批，其他模型不可用/语言/拒绝等错误有限结束。
- 现有 AI 翻译使用所选后端；系统 Translation 引擎保持独立，原提示词、目标语言、译文附件和保存方式保持。
- 当前源文、时间标签、假名与既有过滤修复不因后端接入而变更。旧 remote 配置与凭据保留，切换本地不清空它们。
- 公共后端配置允许本地模式不提供 API key；旧远程调用接口保留适配以便回归。

## 验证

- 无配置迁移、旧默认选择和远程协议回归；本地分支零 HTTP/凭据访问。
- 后端切换、配置快照、请求取消与独立 session；上下文错误、不可用、格式错误和翻译分批预算。
- 假模型单测与真实端侧小样例分开记录；不调用远程模型或 PCC，不修改系统设置/下载模型。
- 设置表单两后端、状态、语言与旧系统能力处理，实际 AppKit探针及完整 Release 构建。
- 独立副本回滚并复测，保留原哈希、补丁和命令输出。
